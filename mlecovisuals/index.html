FAQ

Перед установкой.

Что нужно для мода?

Minecraft 1.21.4, Fabric Loader 0.16.9+ и Java 21. Текущий JAR не требует отдельного Fabric API.

Что делать, если EXE не открыл окно?

Версия 0.2.1 создаёт лог в %LOCALAPPDATA%\\MlekaVoxel\\launcher.log и показывает ошибку, если ни одна найденная Java не смогла запустить launcher.

Можно ли добавить другие моды?

Да. В launcher можно выбрать папку Minecraft и управлять JAR-файлами в папке mods.

Когда заработает покупка?

Как только будет подключён выбранный платёжный провайдер. API-ключ хранится только на сервере; интерфейс уже подготовлен.
