Условия использования

Mleka Voxel является клиентской визуальной модификацией. Пользователь обязан самостоятельно соблюдать правила Minecraft-серверов, на которых играет. Наличие server profile не является гарантией разрешённости всех функций конкретным сервером.

Файлы распространяются в заявленных версиях; перед обновлением Minecraft или Fabric рекомендуется проверять совместимость.
