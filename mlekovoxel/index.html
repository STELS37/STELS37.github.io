Готовый релиз 0.5

Для обычного пользователя нужен только EXE. Launcher сам кладёт MlekaVoxel в mods, проверяет Fabric API и при необходимости запускает официальный Fabric Installer.

Для онлайн-игры всё равно используется аккаунт, уже авторизованный в локальном игровом launcher. При первом входе окно авторизации может открыться один раз.
