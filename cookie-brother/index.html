Cookie Brother

Local cookie import, export, inspection, and cleanup for Chrome and Firefox.

No remote cookie upload

Cookie Brother processes cookie data locally in your browser profile. It supports JSON, Netscape cookies.txt, Set-Cookie headers, Cookie headers, HAR-like cookie data, and Playwright/Puppeteer storageState files.

Read the Privacy Policy for Chrome Web Store and Firefox Add-ons disclosure details.

Import

Paste cookies, read from clipboard, or select a file. Cookie Brother normalizes browser-sensitive fields such as SameSite, Secure, host-only, and expiration values.

Export

Export every cookie from every site, selected domains, or every possible cookie for the current site as JSON, Netscape cookies.txt, or Cookie header text.

Manage

Search, inspect, copy, and delete cookies from a focused popup or the full manager page.
