Privacy Policy

Cookie Brother browser extension

Effective date: May 17, 2026

Cookie Brother is a browser extension for viewing, importing, exporting, and deleting browser cookies. This policy explains how Cookie Brother handles user data for Chrome Web Store, Firefox Add-ons, and browser users.

Cookie Brother processes cookie data locally inside your browser profile. Cookie Brother does not collect, sell, rent, transmit, upload, share, or remotely store your cookies, browsing data, exported files, imported files, settings, or any other personal data.

Data Cookie Brother Handles

Cookie Brother may access or process the following data locally when you use its features:

  • Browser cookies, including cookie name, value, domain, path, expiration, Secure, HttpOnly, SameSite, store ID, and related browser cookie metadata.
  • The active tab URL or domain, used to show cookies for the current website.
  • User-provided cookie import text or files, such as JSON, Netscape cookies.txt, Set-Cookie headers, Cookie headers, HAR-like data, and Playwright/Puppeteer storageState files.
  • User-created cookie export files.
  • Extension settings, such as protected domains, badge count preference, and import overwrite preference.

How Data Is Used

Cookie Brother uses this data only to provide user-facing extension features:

  • Show cookie inventory for the current site or all browser cookies.
  • Import cookies that you intentionally paste or select from a file.
  • Export cookies that you intentionally choose to export.
  • Delete cookies that you intentionally choose to delete.
  • Display cookie counts and cookie metadata.
  • Save local settings for extension behavior.

Cookie Brother does not use user data for advertising, analytics, profiling, creditworthiness, automated decision making, or unrelated purposes.

Data Sharing And Transmission

Cookie Brother does not transmit cookie data or personal data to the developer, to GitHub, to Google, to Mozilla, or to any third party.

Exports are generated locally as files or clipboard text on your device. Imports are read locally from text you paste or files you select.

The extension includes a voluntary donation link for TON / USDT on the TON Network. Opening a wallet link may take you to a wallet application or website outside the extension. Cookie Brother does not send cookie data to that wallet link. Blockchain transfers are public by nature and are handled by the wallet or blockchain network, not by Cookie Brother.

Storage And Retention

Cookie Brother stores only extension settings in browser extension storage. Cookies remain in your browser's cookie store unless you import, modify, export, or delete them using extension features.

Cookie Brother does not keep remote copies of exported or imported cookies. Any files you export remain wherever you save them. You can delete extension settings by removing the extension or clearing extension storage.

Permissions

  • cookies: read, import, export, and delete cookies.
  • <all_urls> / host permissions: access cookies for websites selected by the user or listed in the browser cookie store.
  • activeTab and tabs: identify the current tab domain and open extension pages or donation/privacy links.
  • storage: save local extension settings.
  • contextMenus: provide quick actions from the browser context menu.

Chrome Web Store Limited Use Statement

The use of information received from Chrome APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Cookie Brother uses Chrome API data only for its disclosed cookie-management features and does not transfer this data to others except when the user explicitly exports or copies data from the extension.

Security

Cookie data can grant access to accounts. Treat exported cookie files as sensitive secrets. Only import cookie files from sources you trust, and store exports securely. Cookie Brother is designed to process data locally and avoid remote transmission.

Children

Cookie Brother is a developer utility and is not directed to children. It does not knowingly collect personal data from children.

Changes

This policy may be updated when Cookie Brother changes. The effective date at the top of this page will be updated when changes are made.
